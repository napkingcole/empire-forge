First launch: "Windows protected your PC"

The GitHub download isn't code-signed — a certificate is a yearly cost for a free hobby project — so Windows SmartScreen doesn't recognise it yet and shows a warning the first time you run it. It doesn't mean anything is wrong. To continue:

  1. Click More info.
  2. Click Run anyway.

Wary of running an unsigned file? That's healthy. Every line of Empire Forge is public on GitHub, and the exe is built from it by GitHub's own servers — you can see each build in the repository's Actions tab. The Microsoft Store version, once it's out, skips this step entirely.

What happens when it runs

A console window opens and, a moment later, your browser opens Empire Forge. The app is a small web page served from your own computer — your civs and your game files never leave it. Close the console window to quit.

Clicked it and nothing happened? Your antivirus may have quietly quarantined it. See the FAQ for the fix.
